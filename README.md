# README-Badges

Генератор бейджей для README — **один файл `index.html`**, без сборки и бэкенда.

- статические (`/badge/…`) и динамические бейджи shields.io (GitHub, npm, PyPI, Docker, …)
- live-превью на светлом/тёмном фоне, масштаб, макет «как в README»
- каталог иконок Simple Icons, фирменные цвета, палитра shields.io
- «Набор» бейджей: drag-and-drop, готовые наборы (JS/TS, Python, DevOps, соцсети, GitHub-репо)
- экспорт: Markdown, HTML, URL, reStructuredText, AsciiDoc; раскладки «в строку / столбиком / по центру»
- пресеты, история (10), Share-ссылка (конфиг и набор в query), импорт/экспорт JSON
- RU/EN, светлая/тёмная тема, адаптив до 320px

Запуск: откройте `index.html` двойным кликом или включите GitHub Pages (Settings → Pages → `main` / root).
